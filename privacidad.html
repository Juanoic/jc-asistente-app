Política de privacidad — JC Asistente

JC Asistente es una aplicación de uso personal y privado. Accede solo a la cuenta ia.jc.asist@gmail.com, que pertenece al propio asistente.

  • Los datos de Gmail se usan únicamente para que el asistente lea, ordene y envíe correos de esa cuenta.
  • Los datos se procesan y guardan solo en la computadora del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.
  • El uso de los datos obtenidos de las APIs de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.
  • El acceso puede revocarse en cualquier momento desde https://myaccount.google.com/permissions.

Contacto: ia.jc.asist@gmail.com
